# Echo Community - Media Converter 🎬🚀

برنامج محول الصيغ الاحترافي **Echo Community Media Converter**، مصمم خصيصاً لتسهيل مهام التحويل، قص الفيديو، صناعة الصور المتحركة، والضغط الذكي للديسكورد.

## 🔥 الميزات الأساسية:
- 👾 **الضغط الذكي للديسكورد (Discord Fit):** خوارزمية ذكية تضمن أن حجم أي فيديو لن يتخطى 24.5MB لرفعه في الديسكورد دون مشاكل.
- 🎨 **نظام الألوان (Themes):** 4 ألوان احترافية (Dark Blue, Blood Red, Hacker Green, Cyber Purple).
- 🚀 **تسريع الهاردوير (Hardware Acceleration):** دعم كامل لكروت الشاشة (NVIDIA, AMD, Intel).
- ✂️ **قص الفيديوهات بدقة:** تحديد البداية والنهاية واستخراج أجزاء معينة.
- 🖼️ **صانع الصور المتحركة (GIF):** استخراج صور متحركة عالية الجودة.
- 🎵 **استخراج الصوت السريع:** فصل الصوت عن الفيديو بضغطة زر.
- 🔗 **تكامل مع الديسكورد (Webhooks):** إرسال الملفات الجاهزة تلقائياً للديسكورد بعد الانتهاء.

## 🛠️ المتطلبات لتشغيل الكود المصدري:
\\\ash
pip install customtkinter tkinterdnd2 imageio-ffmpeg pillow requests
\\\

## 💎 تشغيل البرنامج (للمستخدم النهائي):
تستطيع تحميل النسخة الجاهزة للتشغيل (Executable) مباشرة وفتح \MediaConverter.exe\ دون الحاجة لتثبيت أي متطلبات.
